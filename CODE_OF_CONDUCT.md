# Code of Conduct

## Our standard

We are committed to making this project welcoming and productive for
everyone. Contributors are expected to:

- Be respectful and constructive.
- Assume good intentions while addressing technical disagreements directly.
- Welcome different backgrounds, experiences, and viewpoints.
- Focus feedback on the work, not on the person.
- Protect private information and never publish credentials or other sensitive
  data.

Unacceptable behavior includes harassment, discrimination, personal attacks,
sexualized language or attention, threats, trolling, and deliberate disclosure
of private or security-sensitive information.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, commits, and
pull requests that violate this code. They may also temporarily or permanently
restrict participation when necessary to protect the community.

Report problems privately through the [repository maintainer's GitHub
profile](https://github.com/erikhoward).
Security vulnerabilities must be reported according to [SECURITY.md](SECURITY.md).

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
