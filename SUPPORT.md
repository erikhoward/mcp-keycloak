# Support

Check the documentation before opening a support request:

- [README and tool reference](README.md)
- [Installation](docs/install.md)
- [Getting started and troubleshooting](docs/getting-started.md)
- [Client setup](docs/client-setup.md)
- [Event filters](docs/events.md)

For a reproducible bug, open an issue and include the release or commit,
operating system, Go version if relevant, configuration shape with secrets
removed, exact reproduction steps, and the full error message. Do not include
passwords, tokens, client secrets, private URLs, or production data.

For usage questions, describe what you are trying to do and what you expected
to happen. Search existing issues first.

Do not report security vulnerabilities in an issue. Use the process in
[SECURITY.md](SECURITY.md).
